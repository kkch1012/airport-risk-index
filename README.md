# 공항 위험지수 모니터링 시스템 (Airport Risk Index)

실시간으로 국내 공항의 다양한 위험요인을 수집, 분석하여 통합 위험지수를 산출하고 모니터링하는 시스템

## 프로젝트 개요

### 배경
공항은 다양한 위험요인(기상, 보안, 보건, 운영 등)에 노출되어 있으며, 이러한 요인들을 통합적으로 모니터링하고 사전에 위험을 감지할 필요가 있습니다.

### 목표
- 다양한 위험요인 데이터를 실시간으로 수집
- 과거 사고 데이터와의 상관분석을 통한 과학적 가중치 산출
- 통합 위험지수 산출 및 시각화
- 고위험 상황 시 즉각적인 알림 제공

### 대상
- 국내 전체 공항 (15개)
- 해외 위험요인 모니터링 (출발/도착국 기준)

## 주요 기능

### 1. 실시간 데이터 수집
- 기상정보 (기상청 API, METAR)
- 승객/운항 통계 (공항공사)
- 사고/준사고 이력 (ARAIB)
- 전염병 현황 (질병관리청, WHO)
- 보안 위협 정보 (테러경보, 뉴스)
- 해외 위험요인 (여행경보, 국제정세)

### 2. 위험지수 분석
- 6개 카테고리별 위험점수 산출 (0-100)
- 가용 데이터(has_data) 기반 가중치 재정규화 — 데이터 없으면 가짜 점수 대신 제외
- 종합 위험지수 및 위험등급 판정

### 3. 대시보드
- 전체 공항 현황 지도 뷰
- 공항별 상세 위험 분석
- 트렌드 및 비교 분석
- 상관관계 시각화

### 4. 알림 시스템
- 고위험 상황 이메일 알림
- 위험등급 변경 알림
- 임계치 기반 긴급 알림

## 위험 카테고리

| 카테고리 | 코드 | 설명 | 주요 요인 |
|----------|------|------|----------|
| 항공안전 | `AVIATION` | 항공기 운항 관련 위험 | 사고이력, 준사고, 심각도 |
| 보안위협 | `SECURITY` | 테러, 범죄 관련 위험 | 테러/위협, 마약밀수, 불법입국 |
| 보건위험 | `HEALTH` | 전염병, 검역 관련 위험 | 감염병경보, 검역관리지역 수, 발생지 근접도 |
| 운영위험 | `OPERATIONAL` | 항공편 운항 차질 위험 | **지연율(주축)·결항율(보조)** |
| 기상위험 | `WEATHER` | 기상 관련 위험 | 풍속, 강수량, 강수형태, 습도 |
| 외부요인 | `EXTERNAL` | 외부 환경 위험 | 여행경보, 국제정세, 해외기상/항공 |

> **운영위험 재정의(2026-06):** 혼잡도·시설노후도·파업은 모두 공항 운영자 내부데이터라 무료 공개데이터/크롤링으로 확보할 수 없어 제외했습니다. 공개데이터로 산출 가능한 **지연율(0–65점)을 주축, 결항율(0–35점)을 보조**로 재정의했습니다.


## 위험지수 산출 방법

### 1. 데이터 정규화
각 위험요인 값을 0-100 스케일로 정규화 (카테고리별 가중 합산)

### 2. has_data 플래그 & 가중치 재정규화 (핵심)
데이터 소스에서 유효한 데이터를 얻지 못한 카테고리는 `has_data=False`로 표시되며,
**종합 위험지수 계산 시 가중치에서 제외하고 남은 카테고리로 재정규화**합니다.
(가짜 점수를 만들지 않고, 가용 데이터가 전혀 없으면 종합점수 = 0)

```
available = {has_data=True 인 카테고리}
종합 위험지수 = Σ(카테고리점수 × 가중치) / Σ(가중치)   # available 기준 재정규화
```

> 단, **국제선이 없는 국내 전용 공항**의 외부요인/보건위험 LOW는 실제 판정이므로 `has_data=True`로 유지됩니다.

### 3. 카테고리 점수 계산

```
카테고리 점수 = Σ (요인값_정규화 × 요인가중치)
```

### 기본 카테고리 가중치

| 카테고리 | 기본 가중치 |
|----------|------------|
| 항공안전 | 0.25 |
| 보안위협 | 0.20 |
| 기상위험 | 0.20 |
| 보건위험 | 0.15 |
| 운영위험 | 0.10 |
| 외부요인 | 0.10 |

*가용 데이터(has_data) 카테고리만으로 합이 1이 되도록 재정규화하여 적용.*
