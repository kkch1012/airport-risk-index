# 공항 위험지수 모니터링 시스템 (Airport Risk Index)

실시간으로 국내 공항의 다양한 위험요인을 수집, 분석하여 통합 위험지수를 산출하고 모니터링하는 시스템

## 프로젝트 개요

### 배경
공항은 다양한 위험요인(기상, 보안, 보건, 운영 등)에 노출되어 있으며, 이러한 요인들을 통합적으로 모니터링하고 사전에 위험을 감지할 필요가 있습니다.

### 목표
- 다양한 위험요인 데이터를 실시간으로 수집
- 과거 사고 데이터와의 상관분석을 통한 과학적 가중치 산출
- 통합 위험지수 산출 및 시각화
- 고위험 상황 시 즉각적인 알림 제공

### 대상
- 국내 전체 공항 (15개)
- 해외 위험요인 모니터링 (출발/도착국 기준)

## 주요 기능

### 1. 실시간 데이터 수집
- 기상정보 (기상청 API, METAR)
- 승객/운항 통계 (공항공사)
- 사고/준사고 이력 (ARAIB)
- 전염병 현황 (질병관리청, WHO)
- 보안 위협 정보 (테러경보, 뉴스)
- 해외 위험요인 (여행경보, 국제정세)

### 2. 위험지수 분석
- 6개 카테고리별 위험점수 산출 (0-100)
- 상관분석 기반 가중치 자동 산출
- 종합 위험지수 및 위험등급 판정

### 3. 대시보드
- 전체 공항 현황 지도 뷰
- 공항별 상세 위험 분석
- 트렌드 및 비교 분석
- 상관관계 시각화

### 4. 알림 시스템
- 고위험 상황 이메일 알림
- 위험등급 변경 알림
- 임계치 기반 긴급 알림

## 위험 카테고리

| 카테고리 | 코드 | 설명 | 주요 요인 |
|----------|------|------|----------|
| 항공안전 | `AVIATION` | 항공기 운항 관련 위험 | 사고이력, 준사고, 조류충돌, 활주로침범 |
| 보안위협 | `SECURITY` | 테러, 범죄 관련 위험 | 테러경보, 마약밀수, 밀입국, 위험물반입 |
| 보건위험 | `HEALTH` | 전염병, 검역 관련 위험 | 감염병경보, 검역적발, 출발국감염현황 |
| 운영위험 | `OPERATIONAL` | 공항 운영 관련 위험 | 혼잡도, 지연율, 시설노후도, 파업 |
| 기상위험 | `WEATHER` | 기상 관련 위험 | 시정, 풍속, 강수량, 적설, 뇌우 |
| 외부요인 | `EXTERNAL` | 외부 환경 위험 | 여행경보, 국제정세, 항공사안전등급 |

### 위험등급

| 등급 | 점수 범위 | 색상 | 설명 |
|------|----------|------|------|
| LOW | 0-25 | 🟢 녹색 | 정상 상태 |
| MODERATE | 25-50 | 🟡 노란색 | 주의 필요 |
| HIGH | 50-75 | 🟠 주황색 | 경계 상태 |
| CRITICAL | 75-100 | 🔴 빨간색 | 긴급 대응 필요 |

## 설치 및 실행

### 사전 요구사항
- Docker & Docker Compose
- Node.js 18+ (프론트엔드 개발 시)
- Python 3.11+ (백엔드 개발 시)

### 빠른 시작

```bash
# 저장소 클론
git clone <repository-url>
cd airport-risk-index

# 환경변수 설정
cp .env.example .env
# .env 파일 수정 (API 키 등)

# Docker로 전체 실행
docker-compose up -d

# 접속
# - 프론트엔드: http://localhost:3000
# - API 문서: http://localhost:8000/docs
```

### 개발 환경

```bash
# Backend
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# Frontend
cd frontend
npm install
npm run dev
```

## 위험지수 산출 방법

### 1. 데이터 정규화
각 위험요인 값을 0-100 스케일로 정규화

### 2. 상관분석
과거 사고 데이터와 각 요인 간 상관계수 산출
- Pearson 상관계수
- Spearman 상관계수

### 3. 가중치 산출
- 다중회귀분석 (표준화 계수)
- Random Forest Feature Importance
- 도메인 전문가 검증

### 4. 위험지수 계산

```
카테고리 점수 = Σ (요인값_정규화 × 요인가중치)
종합 위험지수 = Σ (카테고리점수 × 카테고리가중치)
```

### 기본 카테고리 가중치

| 카테고리 | 기본 가중치 |
|----------|------------|
| 항공안전 | 0.25 |
| 보안위협 | 0.20 |
| 보건위험 | 0.15 |
| 운영위험 | 0.15 |
| 기상위험 | 0.15 |
| 외부요인 | 0.10 |

*가중치는 상관분석 결과에 따라 주기적으로 갱신됨*
